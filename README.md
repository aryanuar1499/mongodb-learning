# MongoDB Learning

A structured learning journey to understand MongoDB, from database fundamentals to advanced database concepts.

## About

This repository documents my learning journey in MongoDB through structured study, hands-on practice, and technical reflection.

The goal is not only to learn MongoDB syntax, but also to understand how document-oriented databases work, how data is modeled, queried, indexed, and managed in real-world applications.
